# 常见问题

- **连接被拒绝 / 404**：确认服务端口可达、`--base-url` 填根地址或 `/v1`；文本用 `/v1/chat/completions`，随机 token 用 `/v1/completions`。
- **401 / 403 / Model not found**：显式传入 `--api-key`（或设置 `OPENAI_API_KEY`）和服务端公开的 `--model`。
- **400 不支持扩展字段**：压测会请求 `stream_options`、缓存和推测解码扩展统计；对严格校验 schema 的端点请先用 `aib req` 测试。
- **没有 `/flush_cache` 接口**：SGLang 之外的服务可加 `--disable-flush-cache`（遇到 404/405 也会自动快速跳过）。
- **缺少数据集或 tokenizer**：运行 `pip install 'ai-infra-bench[data]'`；ShareGPT 指定长度需传 `--tokenizer` 或 `--model`。
- **会话回放无正式样本**：默认前 3 个会话用于预热，样本少时加 `--num-warmup-sessions 0`。
- **问题反馈**：在 [GitHub Issues](https://github.com/Muqi1029/ai-infra-bench/issues) 提交版本、完整命令与最小复现日志（注意移除密钥）。
