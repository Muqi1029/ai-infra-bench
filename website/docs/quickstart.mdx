# 快速开始

## 1. 安装

需要 Python 3.10+：

```bash
pip install ai-infra-bench
# 需要内置数据集或 tokenizer 时：
pip install 'ai-infra-bench[data]'
```

## 2. 验证连通性

```bash
aib req --base-url http://127.0.0.1:30000 --model your-model --prompt "Who are you?"
```

## 3. 运行压测

```bash
aib bench \
  --base-url http://127.0.0.1:30000 \
  --model your-model \
  --dataset random \
  --input-len 1024 --output-len 256 \
  --num-requests 100 --max-concurrency 1 4 16 \
  --disable-flush-cache \
  --metric-path metrics.jsonl
```

自定义请求可准备 `requests.jsonl`（每行一个 JSON 请求体）并传入 `--payload-path requests.jsonl`。

## 4. 生成可视化报告

```bash
aib plot-metrics metrics.jsonl -o metrics.html
```
