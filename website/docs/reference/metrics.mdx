# 指标与结果

## 压测核心指标

| 指标 | 定义 |
| --- | --- |
| `TTFT` | 请求发出到收到首个非空内容/推理/工具调用增量的时间（ms） |
| `ITL` | 首个增量之后相邻流式增量之间的间隔（ms） |
| `TPOT` | `(latency_ms - ttft_ms) / (completion_tokens - 1)`（ms/token） |
| `Latency` | 单次 HTTP 请求耗时，不含客户端排队（ms） |
| `Input throughput` | 成功请求的输入 token 总数 / 总耗时（tokens/s） |
| `Output throughput` | 成功请求的输出 token 总数 / 总耗时（tokens/s） |
| `Total token throughput` | 成功请求的输入+输出 token 总数 / 总耗时（tokens/s） |
| `Request goodput` | 同时满足 `--goodput` 阈值的请求吞吐量与占比 |
| `Cached tokens` | 服务端返回的缓存命中 token 数 |

## 保存与绘图

```bash
aib bench --dataset random --input-len 1024 --output-len 256 \
  --num-requests 100 --max-concurrency 1 8 32 \
  --disable-flush-cache --metric-path metrics.jsonl --label baseline

aib plot-metrics metrics.jsonl -o metrics.html
```

- `--metric-path`：`*.json` 覆盖写入，`*.jsonl` 追加一行聚合结果。
- `--dump-path`：导出逐请求 JSONL（`--dump-content all|msg`、`--dump-finish-reason-length`）。

## SLO 指标名称

`conditions[].metric` 支持：

- **计数与吞吐**：`total_requests`、`successful_requests`、`failed_requests`、`success_rate`、`duration_s`、`max_concurrency`、`request_rate`、`request_throughput`、`input_throughput`、`output_throughput`、`total_token_throughput`
- **分布统计**：`mean_` / `p50_` / `p95_` / `p99_` + `ttft_ms`、`tpot_ms`、`itl_ms`、`latency_ms`、`e2e_latency_ms`、`prompt_tokens`、`completion_tokens`、`reasoning_tokens`、`cached_tokens`
