# 命令行参考

使用 `aib --help` 或 `aib <command> --help` 查看完整选项。

## 命令一览

| 命令 | 用途 |
| --- | --- |
| `req` | 发送单个推理请求（支持 `--payload-path -` / `--prompt -`） |
| `bench` | 性能压测与自定义请求回放 |
| `slo` | YAML 驱动的 SLO 二分容量搜索 |
| `session-bench` | 会话级并发多轮回放（别名 `session-reply-bench`） |
| `eval-dataset` | 数据集正确性评测 |
| `eval-logits` | 多端点 Top-K logprobs 对比 |
| `eval-hidden-states` | 多端点隐藏状态对比 |
| `plot-metrics` | 导出交互式 Plotly HTML 报告 |
| `monitor` | 本地 Prometheus + Grafana 监控 |
| `reply` | 回放记录并导出 input/output token ID |
| `check-device` | 仅用标准库与 NVIDIA 驱动检查 GPU 硬件规格 |
| `check-weight` | 轻量检查 safetensors / `.bin` 权重参数量 |
| `profile-sgl` | 启动或停止 SGLang profiling |
| `token` | Hugging Face tokenizer 编码/解码（别名 `tokenize`） |

## 通用连接参数

适用于 `req`、`bench`、`session-bench`、`eval-dataset`、`eval-logits`、`eval-hidden-states`、`reply`：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--base-url` | `127.0.0.1:30000` | 服务地址（`eval-logits` / `eval-hidden-states` 用 `--base-urls`） |
| `--api-key` | `OPENAI_API_KEY` 或 `JustKeepMe` | Bearer Token |
| `--model` | 未设置 | 请求模型名 |
| `--override-payload` | 未设置 | 覆盖顶层请求字段的 JSON 对象 |
| `--seed` | `42` | 随机种子 |

## 常用 `bench` 参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--dataset` | `random` | `random` / `gsm8k` / `gpqa` / `sharegpt` |
| `--payload-path` | 未设置 | JSON/JSONL 文件、glob 或 `-`（stdin），兼容 `--payload-regex-path` |
| `--num-requests` | random/ShareGPT 为 `100` | 正式压测请求数 |
| `--max-concurrency` | `32` | 可指定多个并发值 |
| `--request-rate` | `inf` | 到达速率（req/s） |
| `--input-len` / `--output-len` | `8192` / `1024` | 目标输入/输出长度 |
| `--num-warmup-requests` | `10` | 预热请求数（设为 `0` 禁用预热） |
| `--goodput` | 未设置 | Goodput SLO 阈值，如 `ttft:500 tpot:50` |
| `--disable-flush-cache` | 关闭 | 跳过 `/flush_cache` 调用 |
| `--metric-path` | `aib-metric.jsonl` | 聚合指标输出路径 |

## 硬件、权重与 Token 工具

```bash
aib check-device --json
aib check-weight --path /path/to/model
aib token --tokenizer /path/to/tokenizer "Hello world"
echo '[1, 2, 3]' | aib token --tokenizer /path/to/tokenizer --decode -
```
