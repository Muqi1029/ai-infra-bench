# 正确性评测

## 数据集评测（`eval-dataset`）

```bash
pip install 'ai-infra-bench[data]'
aib eval-dataset --evals gsm8k --base-url http://127.0.0.1:30000 --model your-model --num-questions 50
```

| `--evals` | 说明 |
| --- | --- |
| `gsm8k` | 小学数学文字题（支持 few-shot） |
| `gpqa` | GPQA Diamond 多项选择 |
| `aime25` | AIME 2025 数学题 |
| `hle` | Humanity's Last Exam 纯文本子集（支持 `--dataset-path ./hle.jsonl`） |
| `constrained_decoding` | Tool call 与 JSON Schema 约束解码 |
| `deepswe` | 通过 Pier 执行的软件工程评测（需 `ai-infra-bench[deepswe]`） |

- 评测自动过滤 `<think>...</think>` 推理过程后再提取答案，并统计截断率（`finish_reason=length`）与多轮（`--repeat > 1`）均值/标准差。

## Logits 与 Hidden States 对比

```bash
# 对比两个端点的首 token Top-K logprobs（首个为参考端点）
aib eval-logits \
  --base-urls http://127.0.0.1:30000 http://127.0.0.1:30001 \
  --model your-model --prompt "The capital of France is" --atol 0.01

# 对比扩展 hidden states 输出
aib eval-hidden-states \
  --base-urls http://127.0.0.1:30000 http://127.0.0.1:30001 \
  --model your-model --atol 0.01
```
