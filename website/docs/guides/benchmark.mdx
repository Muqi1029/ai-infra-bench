# 性能压测

`aib bench` 支持随机 token、内置数据集与自定义请求回放，并统计 TTFT、ITL、TPOT、吞吐量与 Goodput。

## 随机 token 压测

```bash
aib bench \
  --base-url http://127.0.0.1:30000 \
  --model your-model \
  --dataset random \
  --input-len 1024 --output-len 256 \
  --num-requests 100 \
  --max-concurrency 1 4 16 \
  --repeat 2 \
  --goodput ttft:500 tpot:50 \
  --metric-path metrics.jsonl
```

- `--max-concurrency` 支持传入多个并发度依次测试；`--repeat` 控制每档重复次数。
- `--num-warmup-requests 0` 可关闭预热；不支持 `/flush_cache` 的通用服务需传入 `--disable-flush-cache`。
- `--goodput` 统计同时满足给定毫秒阈值的请求吞吐与占比（支持 `ttft`、`tpot`、`itl`、`e2el`）。

## 长度分布与前缀缓存

- `--random-range-ratio 0.5`：输入/输出长度在 `[0.5 * target, target]` 内均匀采样（默认 `1.0` 固定长度）。
- `--cache-ratio 0.5`：所有请求共享 `int((input_len - 1) * 0.5)` 个前缀 token，每次正式运行前自动预热该前缀。

## 内置数据集与自定义回放

```bash
# 内置数据集（gsm8k / gpqa / sharegpt）
aib bench --dataset sharegpt --model your-model \
  --input-len 1024 --output-len 256 --num-requests 100 --disable-flush-cache

# 自定义 JSON / JSONL / Glob / stdin(-)
aib bench --payload-path 'requests/**/*.jsonl' --max-concurrency 16 --disable-flush-cache
cat request.json | aib bench --payload-path - --num-requests 50 --disable-flush-cache
```
