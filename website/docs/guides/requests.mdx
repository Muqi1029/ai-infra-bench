# 发送请求

`aib req` 用于验证服务连通性、观察流式输出及调试请求体。

## 文本与流式模式

```bash
aib req \
  --base-url http://127.0.0.1:30000 \
  --api-key "$OPENAI_API_KEY" \
  --model your-model \
  --prompt "What is prefix caching?"
```

- 默认启用流式输出；`--disable-stream` 改为非流式 JSON，`--raw` 打印原始 SSE，`--no-print` 仅输出统计表。
- `--api-key` 默认读取 `OPENAI_API_KEY`（缺省 `JustKeepMe`）。

## 从文件或 stdin 读取

```bash
# 从 JSON 文件发送
aib req --payload-path request.json

# 从 stdin 读取 JSON 请求体（以下两种等价）
cat request.json | aib req --payload-path - --model your-model
cat request.json | aib req

# 从 stdin 读取纯文本 prompt
cat prompt.txt | aib req --prompt - --max-tokens 128
```

包含 `prompt` 且不含 `messages` 的请求会自动路由到 `/v1/completions`。

## 覆盖与扩展参数

```bash
aib req --prompt "What is a GPU?" --max-tokens 128 \
  --override-payload '{"temperature":0}'
```

- `--override-payload` 按顶层键覆盖请求体（优先级高于 `--model`）。
- `--enable-thinking` / `--disable-thinking`、`--tools`、`--response-format-json-schema`、`--ebnf` 需服务端支持。
- `--verbose` 会打印完整请求头与请求体（注意脱敏密钥）。
