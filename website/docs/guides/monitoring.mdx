# 本地监控

`aib monitor` 在本地启动 Prometheus 与 Grafana（内置 SGLang 看板），并在交互终端中支持动态增删目标。被测服务需开启 `--enable-metrics`。

```bash
aib monitor --base-urls http://127.0.0.1:30000 --open
```

- 默认地址：Prometheus `http://127.0.0.1:9090`，Grafana `http://127.0.0.1:3000`。

| 参数 | 说明 |
| --- | --- |
| `--runtime auto\|system\|download` | 自动解析或下载经过校验的二进制 |
| `--no-grafana` | 仅运行 Prometheus |
| `--scrape-interval 5s` | 采集周期（默认 `5s`） |
| `--runtime-dir PATH` | 配置与日志目录 |
| `--dry-run` | 仅生成配置不启动进程 |
