# AI Infra Bench

A lightweight CLI for OpenAI-compatible inference endpoints: benchmark latency and throughput, search SLO capacity, evaluate accuracy, and inspect hardware/weights without serving-framework SDKs.

:::info Endpoint Compatibility
- Text requests use `/v1/chat/completions`; random token-ID benchmarks use `/v1/completions`.
- `aib bench` requires SSE streaming; cache details, speculative metrics, and `/flush_cache` require server support.
- See [Troubleshooting](./troubleshooting.mdx) if strict endpoints reject extension fields.
:::
