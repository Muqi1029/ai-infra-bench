# Local Monitoring

`aib monitor` runs local Prometheus and Grafana processes with a bundled SGLang dashboard and an interactive shell for managing scrape targets. Ensure SGLang is started with `--enable-metrics`.

```bash
aib monitor --base-urls http://127.0.0.1:30000 --open
```

- Defaults: Prometheus `http://127.0.0.1:9090`, Grafana `http://127.0.0.1:3000`.

| Option | Description |
| --- | --- |
| `--runtime auto\|system\|download` | Use local binaries or download verified releases |
| `--no-grafana` | Run Prometheus only |
| `--scrape-interval 5s` | Scrape interval (default `5s`) |
| `--runtime-dir PATH` | Configuration and log directory |
| `--dry-run` | Generate configs without starting services |
