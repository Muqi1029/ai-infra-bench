# Evaluation

## Dataset Evaluation (`eval-dataset`)

```bash
pip install 'ai-infra-bench[data]'
aib eval-dataset --evals gsm8k --base-url http://127.0.0.1:30000 --model your-model --num-questions 50
```

| `--evals` | Description |
| --- | --- |
| `gsm8k` | Grade-school math word problems (supports few-shot) |
| `gpqa` | GPQA Diamond multiple-choice questions |
| `aime25` | AIME 2025 math problems |
| `hle` | Text-only Humanity's Last Exam (supports `--dataset-path ./hle.jsonl`) |
| `constrained_decoding` | Tool calling and JSON schema constrained decoding |
| `deepswe` | Software engineering tasks via Pier (requires `ai-infra-bench[deepswe]`) |

- `<think>...</think>` blocks are stripped before answer extraction; output tables also track length-truncated requests and multi-round (`--repeat > 1`) mean/std accuracy.

## Logits & Hidden States Comparison

```bash
# Compare Top-K logprobs across endpoints (first URL is reference)
aib eval-logits \
  --base-urls http://127.0.0.1:30000 http://127.0.0.1:30001 \
  --model your-model --prompt "The capital of France is" --atol 0.01

# Compare hidden states extension outputs
aib eval-hidden-states \
  --base-urls http://127.0.0.1:30000 http://127.0.0.1:30001 \
  --model your-model --atol 0.01
```
