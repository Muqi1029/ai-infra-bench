# Benchmarking

`aib bench` supports synthetic random tokens, packaged datasets, and custom payload replay, reporting TTFT, ITL, TPOT, token throughput, and Goodput.

## Random-Token Workload

```bash
aib bench \
  --base-url http://127.0.0.1:30000 \
  --model your-model \
  --dataset random \
  --input-len 1024 --output-len 256 \
  --num-requests 100 \
  --max-concurrency 1 4 16 \
  --repeat 2 \
  --goodput ttft:500 tpot:50 \
  --metric-path metrics.jsonl
```

- `--max-concurrency` accepts multiple values sequentially; `--repeat` repeats each concurrency level.
- Pass `--num-warmup-requests 0` to skip warmup; pass `--disable-flush-cache` when `/flush_cache` is unavailable.
- `--goodput` reports request rate and percentage meeting every threshold in ms (`ttft`, `tpot`, `itl`, `e2el`).

## Length Sampling & Prefix Cache

- `--random-range-ratio 0.5`: sample lengths uniformly in `[0.5 * target, target]` (default `1.0`).
- `--cache-ratio 0.5`: share `int((input_len - 1) * 0.5)` prefix tokens across requests and prime the prefix before each measured run.

## Packaged Datasets & Custom Replay

```bash
# Packaged datasets (gsm8k / gpqa / sharegpt)
aib bench --dataset sharegpt --model your-model \
  --input-len 1024 --output-len 256 --num-requests 100 --disable-flush-cache

# Custom JSON / JSONL / glob / stdin (-)
aib bench --payload-path 'requests/**/*.jsonl' --max-concurrency 16 --disable-flush-cache
cat request.json | aib bench --payload-path - --num-requests 50 --disable-flush-cache
```
