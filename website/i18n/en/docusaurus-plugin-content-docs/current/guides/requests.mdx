# Send Requests

Use `aib req` to verify connectivity, inspect streamed output, and debug payloads.

## Text & Streaming

```bash
aib req \
  --base-url http://127.0.0.1:30000 \
  --api-key "$OPENAI_API_KEY" \
  --model your-model \
  --prompt "What is prefix caching?"
```

- Streaming is enabled by default; pass `--disable-stream` for JSON responses, `--raw` for raw SSE lines, or `--no-print` to suppress streamed text.
- `--api-key` reads `OPENAI_API_KEY` by default (fallback `JustKeepMe`).

## Files & Stdin

```bash
# Send from a JSON file
aib req --payload-path request.json

# Read a JSON payload from stdin
cat request.json | aib req --payload-path - --model your-model
cat request.json | aib req

# Read a plain-text prompt from stdin
cat prompt.txt | aib req --prompt - --max-tokens 128
```

Payloads with `prompt` (and without `messages`) automatically route to `/v1/completions`.

## Overrides & Extra Flags

```bash
aib req --prompt "What is a GPU?" --max-tokens 128 \
  --override-payload '{"temperature":0}'
```

- `--override-payload` merges at the top level (taking precedence over `--model`).
- `--enable-thinking`, `--disable-thinking`, `--tools`, `--response-format-json-schema`, and `--ebnf` depend on server support.
- `--verbose` prints headers and payload (redact keys before sharing).
