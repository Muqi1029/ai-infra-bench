# Troubleshooting

- **Connection refused / 404**: Verify the server address; `--base-url` accepts a root URL or `/v1`. Text uses `/v1/chat/completions`; random tokens use `/v1/completions`.
- **401 / 403 / Model not found**: Pass `--api-key` (or set `OPENAI_API_KEY`) and the exact `--model` served by your endpoint.
- **400 unsupported fields**: Benchmarks request `stream_options` and extended cache/speculative stats; verify endpoint compatibility with `aib req` first.
- **No `/flush_cache` endpoint**: Pass `--disable-flush-cache` on non-SGLang servers (HTTP 404/405 responses are also skipped immediately).
- **Missing datasets or tokenizers**: Install `'ai-infra-bench[data]'`; ShareGPT length resizing requires `--tokenizer` or `--model`.
- **No measured sessions**: The first 3 sessions are warmup by default; pass `--num-warmup-sessions 0` for small session sets.
- **Bug reports**: Open a [GitHub Issue](https://github.com/Muqi1029/ai-infra-bench/issues) with AIB/Python versions, command, and redacted error logs.
