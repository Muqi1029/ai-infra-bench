# CLI reference

Run `aib --help` or `aib <command> --help` for full option details.

## Commands

| Command | Purpose |
| --- | --- |
| `req` | Send a single request (supports `--payload-path -` / `--prompt -`) |
| `bench` | Performance benchmark and payload replay |
| `slo` | YAML-driven SLO binary search |
| `session-bench` | Session-level multi-turn replay (alias `session-reply-bench`) |
| `eval-dataset` | Dataset accuracy evaluation |
| `eval-logits` | Multi-endpoint Top-K logprob comparison |
| `eval-hidden-states` | Multi-endpoint hidden-state comparison |
| `plot-metrics` | Export aggregate metrics to interactive HTML |
| `monitor` | Local Prometheus + Grafana monitoring |
| `reply` | Replay payloads and save input/output token IDs |
| `check-device` | Inspect NVIDIA GPUs using stdlib + CUDA driver only |
| `check-weight` | Lightweight safetensors / `.bin` weight inspection |
| `profile-sgl` | Start or stop SGLang profiling |
| `token` | Encode/decode via Hugging Face tokenizer (alias `tokenize`) |

## Common Connection Options

Shared across `req`, `bench`, `session-bench`, `eval-dataset`, `eval-logits`, `eval-hidden-states`, and `reply`:

| Option | Default | Description |
| --- | --- | --- |
| `--base-url` | `127.0.0.1:30000` | Endpoint URL (`eval-logits` / `eval-hidden-states` use `--base-urls`) |
| `--api-key` | `OPENAI_API_KEY` or `JustKeepMe` | Bearer token |
| `--model` | Unset | Target model name |
| `--override-payload` | Unset | JSON object overriding top-level request fields |
| `--seed` | `42` | Random generation seed |

## Common `bench` Options

| Option | Default | Description |
| --- | --- | --- |
| `--dataset` | `random` | `random`, `gsm8k`, `gpqa`, or `sharegpt` |
| `--payload-path` | Unset | JSON/JSONL file, glob, or `-` (stdin); alias `--payload-regex-path` |
| `--num-requests` | `100` for random/ShareGPT | Measured request count |
| `--max-concurrency` | `32` | Accepts multiple integers |
| `--request-rate` | `inf` | Arrival rate (req/s) |
| `--input-len` / `--output-len` | `8192` / `1024` | Target lengths |
| `--num-warmup-requests` | `10` | Warmup requests (`0` to disable) |
| `--goodput` | Unset | Goodput thresholds in ms, e.g. `ttft:500 tpot:50` |
| `--disable-flush-cache` | Off | Skip `/flush_cache` calls |
| `--metric-path` | `aib-metric.jsonl` | Aggregate metrics output path |

## Hardware, Weight & Token Utilities

```bash
aib check-device --json
aib check-weight --path /path/to/model
aib token --tokenizer /path/to/tokenizer "Hello world"
echo '[1, 2, 3]' | aib token --tokenizer /path/to/tokenizer --decode -
```
