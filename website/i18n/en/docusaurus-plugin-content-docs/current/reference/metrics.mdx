# Metrics and results

## Core Benchmark Metrics

| Metric | Definition |
| --- | --- |
| `TTFT` | Time from HTTP send to the first nonempty content, reasoning, or tool-call delta (ms) |
| `ITL` | Inter-token interval between consecutive streaming deltas after the first token (ms) |
| `TPOT` | `(latency_ms - ttft_ms) / (completion_tokens - 1)` (ms/token) |
| `Latency` | End-to-end HTTP request duration excluding client queueing (ms) |
| `Input throughput` | Prompt tokens across successful requests / duration (tokens/s) |
| `Output throughput` | Completion tokens across successful requests / duration (tokens/s) |
| `Total token throughput` | Combined prompt + completion tokens across successful requests / duration (tokens/s) |
| `Request goodput` | Request rate and share meeting all `--goodput` thresholds |
| `Cached tokens` | Cache-hit token count reported by the server |

## Save & Plot

```bash
aib bench --dataset random --input-len 1024 --output-len 256 \
  --num-requests 100 --max-concurrency 1 8 32 \
  --disable-flush-cache --metric-path metrics.jsonl --label baseline

aib plot-metrics metrics.jsonl -o metrics.html
```

- `--metric-path`: `*.json` overwrites; `*.jsonl` appends one aggregate record per run.
- `--dump-path`: exports per-request JSONL (`--dump-content all|msg`, `--dump-finish-reason-length`).

## SLO Metric Names

`conditions[].metric` supports:

- **Counts & throughput**: `total_requests`, `successful_requests`, `failed_requests`, `success_rate`, `duration_s`, `max_concurrency`, `request_rate`, `request_throughput`, `input_throughput`, `output_throughput`, `total_token_throughput`
- **Distributions**: `mean_` / `p50_` / `p95_` / `p99_` + `ttft_ms`, `tpot_ms`, `itl_ms`, `latency_ms`, `e2e_latency_ms`, `prompt_tokens`, `completion_tokens`, `reasoning_tokens`, `cached_tokens`
